## 🛠️ Detailed Task Breakdown

### Task 1: Interactive SVG Visual Charts & Gauges
* [ ] **1.1 Loan / EMI Calculator (`LoanEmiCalculator.astro`)**:
  * Implement dynamic SVG Donut Chart for Principal vs Total Interest breakdown with animated stroke-dashoffset.
  * Real-time hover tooltips displaying exact amounts and percentages.
* [ ] **1.2 SIP & Compound Interest Calculators (`SipCalculator.astro`, `CompoundInterestCalculator.astro`)**:
  * Build responsive SVG Area/Line Chart plotting Total Invested vs Future Value over 1–30 years.
  * Interactive coordinates with milestone data points and hover inspection.
* [ ] **1.3 BMI Calculator (`BmiCalculator.astro`)**:
  * Semi-circular SVG Rainbow Gauge (Blue $\rightarrow$ Green $\rightarrow$ Yellow $\rightarrow$ Red).
  * Smooth animated pivot needle pointing to calculated BMI index.
* [ ] **1.4 Rent vs Buy Calculator (`RentVsBuyCalculator.astro`)**:
  * Side-by-side milestone comparison bars for 5, 10, 15, 20, 25, 30 years net wealth.
